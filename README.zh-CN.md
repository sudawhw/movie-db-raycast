# Movie db

[English README](README.md)

适用于 Mac 的 Raycast 本地扩展。输入中英文影视名称，从豆瓣搜索结果选择作品，查看海报、中文简介、演职员资料及豆瓣 / IMDb / 烂番茄评分。

## 安装与配置

1. 安装 Raycast 和 Node.js 22.22.2 或更新版本。
2. 在本文件夹运行 `npm install`、`npm run dev`，导入扩展。
3. 打开扩展设置，按需填写以下凭证，已填写的 OMDb / ApiZero 密钥会保留。

| 设置 | 用途 | 申请地址 |
| --- | --- | --- |
| OMDb API Key | IMDb 和烂番茄评分 | https://www.omdbapi.com/apikey.aspx |
| ApiZero API Key | 豆瓣评分及部分中文资料 | https://apizero.cn/aidocs/douban-movie |
| TMDB API Key / Read Access Token | 海报、中文简介、演职员资料 | https://www.themoviedb.org/settings/api |

获取密钥步骤：

1. **TMDB**：注册并登录 [TMDB](https://www.themoviedb.org/signup)，进入 [设置 → API](https://www.themoviedb.org/settings/api)，申请开发者访问权限，复制 API Key 或 API Read Access Token。
2. **OMDb**：打开 [API Key 申请页](https://www.omdbapi.com/apikey.aspx)，选择套餐并填写信息，按收到的邮件说明激活密钥。
3. **ApiZero**：在 [ApiZero](https://apizero.cn/) 注册并登录，在账户控制台创建 API Key，查看[豆瓣电影接口](https://apizero.cn/aidocs/douban-movie)的调用额度。
4. 在 Raycast 的 Movie db 扩展设置中分别填写相应密钥。语言选项为 **Language / 语言**，默认 English，可切换简体中文。影视标题和简介仍使用来源提供的语言。

TMDB 支持 API 设置页上的 **API Key（32 位）**或 **API Read Access Token（长字符串）**，任填一种即可。无需同时填写，也不要填写 TMDB 登录密码。密钥存放于 Raycast 的密码型偏好设置中。个人非商业使用应遵守 TMDB 的条款及署名要求。

搜索结果中选择作品，按回车打开详情；按 ⌘K 可刷新资料、打开各来源网站、进入设置或查看资料来源说明。可在 Raycast 设置里给「Search Movies and TV」配置快捷键或别名。

## 数据与匹配

- 海报：TMDB → 已缓存的豆瓣海报 → OMDb。豆瓣海报携带来源信息下载后显示，缓存 7 天。
- 简介：豆瓣中文 → TMDB 简体中文 → TMDB 繁体中文 → 其他语言资料 → OMDb 英文。每条简介显示实际来源；不自动生成或翻译简介。
- 演职员：导演优先用豆瓣中文资料，TMDB 补充主演、主创、类型等信息；演员姓名是否中文取决于数据源。
- 豆瓣评分：ApiZero → 用户配置的备用接口 → 豆瓣网页。ApiZero 的免费额度和会员限制以接口文档为准。
- IMDb / 烂番茄评分：OMDb，部分条目可能缺分。TMDB 自身的用户评分不代替三站评分。

优先通过维基百科和维基数据关联 IMDb ID，要求豆瓣 ID 一致。TMDB 优先按 IMDb ID 查找；缺少 ID 时要求名称和年份唯一匹配，并区分已知的电视剧条目。多个同名候选时提示未匹配，不随意选择。豆瓣单季与 TMDB / IMDb 整剧可能不同，请核对详情页的网站链接。

搜索仍以豆瓣为入口，豆瓣找不到的片名无法通过 TMDB 独立发现。

## 缓存与失败处理

搜索缓存 5 分钟，成功返回的评分与资料缓存 6 小时，维基关联资料缓存 7 天。重复查看优先用缓存；Raycast 可能自动回收缓存。操作菜单中的「刷新评分与资料」清除扩展请求缓存并重新查询，海报缓存保留。

输入新片名会取消旧搜索，相同详情的并发请求合并。HTTP 401 / 403 / 429 不重试，临时网络或服务端失败最多重试一次。空搜索、业务失败和 OMDb 未匹配结果不长期缓存。TMDB 和评分分别加载，TMDB 不可用时保留其他来源的资料。

## 自定义备用豆瓣接口

可在设置填入带 `{id}` 的 HTTPS 地址，例如 `https://example.com/movie/{id}`，返回 JSON 中的 `score` 或 `data.score`，评分为 10 分制。示例地址不能使用，需要自行提供兼容服务。

## 隐私与署名

搜索内容发送至豆瓣，选中的豆瓣 ID 发至 ApiZero 和已配置的备用接口。片名会发至维基百科；IMDb ID、片名和年份用于 OMDb / TMDB 匹配。凭证仅发送给相应服务商，不共享给其他来源。请求日志只记录服务域名和耗时，不记录完整 URL 或密钥。请求缓存使用凭证与请求的哈希区分，不直接保存密钥。

This product uses the TMDB API but is not endorsed or certified by TMDB.

## 验证

`npm test` 运行模拟接口测试，不消耗额度；`npm run build` 构建扩展。真实 TMDB 数据需要填写自己的有效凭证后检查。

## Telegram 网盘检索

在影视详情按回车搜索频道，搜索词可手动修改。插件并行读取设置中指定的 Telegram 频道的公开搜索页面，提取可直接识别的 115、百度和夸克网盘链接，按此顺序显示；每个结果提供原频道消息入口。无结果页面按 ⌘K 可打开对应频道的公开搜索页。

仅搜索公开页面返回的首批消息，不代表频道全部历史；私有、限制公开预览、按钮跳转或未直接写明链接的内容可能无法读取。插件不登录 Telegram，搜索词会发送给 Telegram；分享链接可能失效、需要提取码或需要网盘登录。请核对原消息和资源信息。

在 Raycast 扩展设置的「Telegram Search Channels」中维护完整频道列表。默认包含原有七个频道及 @XiangxiuNBB；用逗号或空格分隔，可填写 @用户名、用户名或 t.me 频道链接。删除某项即可停止搜索该频道；留空恢复默认。格式无效的条目会在搜索结果中提示。也可以在网盘搜索页按 ⌘K 选择「管理搜索频道」。Telegram 频道可能更换公开用户名，插件会识别页面中可验证的现用消息地址。

网盘结果默认启用「仅片名匹配」：剔除仅正文提及关键词、名称不同或续作编号不同的消息，忽略标题中的年份和规格后进行匹配。右上角可切换「显示全部结果」排查遗漏。按 115、百度、夸克、需要领取链接分组，同组优先最新发布；严格匹配可能漏掉异名作品，可修改搜索词。

原帖中「点击跳转」若实际指向网盘，直接提取目标链接。指向另一条公开 Telegram 消息的获取入口会尝试跟进一次（自动处理最多 8 个入口），也可通过操作菜单再次尝试获取；不跟进任意外部中转网站。机器人领取入口独立显示，按回车打开 Telegram 入口，由用户在已登录的 Telegram 中完成领取；插件不登录账号、不发送机器人消息，不能自动生成专属分享链接。

## 分享状态检测

对 115、百度和夸克直链自动查询公开分享状态，不登录账号、不转存、不下载文件；请求仅带分享码与链接中的提取码。115 使用公开分享信息，百度识别失效页并在链接自带提取码时验证分享，夸克使用访客分享验证。明确返回「分享已取消 / 已失效 / 已过期 / 已删除」时默认隐藏。分享信息能正常返回时标记为「可访问」，不代表已验证文件能够下载。正常与失效状态在本次命令运行期间缓存 5 分钟，无法确认的状态缓存 30 秒。

检测最多并发 4 条，不阻塞其他来源展示。网络错误、限流、访问码错误或要求登录都标记为「待确认」并保留。打开这三种网盘链接前也会检测；操作菜单可选择「重新检测链接」，右上角「显示全部（含失效）」可查看被隐藏的结果。百度缺少提取码时保留待确认；验证码、登录限制、访问码错误不会被视为失效。机器人领取入口仍不自动验证有效性。
